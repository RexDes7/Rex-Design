## Проблема: После ввода логина и пароля ничего не происходит

### Решение

#### 1. Убедитесь, что сервер разработки запущен

```bash
npm run dev
```

Сервер должен запуститься на `http://localhost:3000`

#### 2. Откройте страницу логина

Перейдите по адресу: `http://localhost:3000/admin/login`

#### 3. Используйте правильные учетные данные

- **Email**: `baracuda.max1@gmail.com`
- **Password**: `Raf070100`

#### 4. Проверьте консоль браузера на наличие ошибок

Откройте DevTools (F12) и перейдите на вкладку Console. Если есть ошибки, они будут отображаться там.

#### 5. Проверьте вкладку Network

В DevTools перейдите на вкладку Network и посмотрите на запрос к `/api/admin/auth/login`:
- Статус должен быть 200 (успех)
- Если 401 - неверные учетные данные
- Если 429 - слишком много попыток входа (подождите 15 минут)
- Если 500 - ошибка сервера

### Проверка базы данных

Если база данных не инициализирована, выполните:

```bash
npm run db:init
```

Это создаст:
- Все необходимые таблицы
- Пользователя admin с указанными выше учетными данными

### Проверка пользователя

Чтобы убедиться, что пользователь создан:

```bash
npx tsx scripts/check-user.ts
```

### Тестирование логина

Чтобы протестировать логин без браузера:

```bash
npx tsx scripts/test-login.ts
```

## Возможные причины проблемы

### 1. Сервер не запущен
**Симптом**: Страница не загружается или показывает ошибку подключения

**Решение**: Запустите `npm run dev`

### 2. JavaScript отключен в браузере
**Симптом**: Форма не отправляется

**Решение**: Включите JavaScript в настройках браузера

### 3. Блокировка CORS
**Симптом**: Ошибка CORS в консоли

**Решение**: Убедитесь, что вы открываете страницу через `localhost:3000`, а не через `file://`

### 4. Превышен лимит попыток входа
**Симптом**: Сообщение "Too many login attempts"

**Решение**: Подождите 15 минут или перезапустите сервер

### 5. База данных не инициализирована
**Симптом**: Ошибка "User not found" или ошибка базы данных

**Решение**: Выполните `npm run db:init`

### 6. Неверные учетные данные
**Симптом**: Сообщение "Invalid credentials"

**Решение**: Используйте правильные учетные данные (см. выше)

## Отладка

### Проверка логов сервера

Посмотрите на вывод терминала, где запущен `npm run dev`. Там должны отображаться все запросы и ошибки.

### Проверка cookie

После успешного входа в DevTools -> Application -> Cookies должен появиться cookie `auth-token`.

### Проверка редиректа

После успешного входа должен произойти редирект на `/admin` (главная страница админ-панели).

## Дополнительная помощь

Если проблема не решена:

1. Проверьте, что все зависимости установлены: `npm install`
2. Очистите кэш Next.js: удалите папку `.next` и перезапустите сервер
3. Проверьте версию Node.js: должна быть >= 18
4. Проверьте, что порт 3000 не занят другим приложением

## Структура админ-панели

После успешного входа вы получите доступ к:

- **Dashboard** (`/admin`) - Главная страница с статистикой
- **Projects** (`/admin/projects`) - Управление проектами
- **Content** (`/admin/content`) - Редактирование контента сайта
- **Analytics** (`/admin/analytics`) - Аналитика посещений
- **Logs** (`/admin/logs`) - Системные логи
- **Settings** (`/admin/settings`) - Настройки и бэкапы
