# Упрощенная админка - Требования

## Цель
Создать простую и рабочую админ-панель для управления портфолио сайтом без излишней сложности.

## Основные принципы
- Простота превыше всего
- Минимум зависимостей
- Работает из коробки
- SQLite база данных (файл на компе)
- Без сложной безопасности (для личного использования)

## Функциональные требования

### 1. Авторизация
**1.1 Логин**
- Страница логина `/admin/login`
- Поля: email и password
- Токен сохраняется в localStorage
- После логина редирект на `/admin`

**1.2 Защита страниц**
- Все страницы `/admin/*` требуют авторизации
- Проверка токена на клиенте (в layout)
- Если токена нет - редирект на `/admin/login`

**1.3 Logout**
- Кнопка "Выйти" в header
- Удаляет токен из localStorage
- Редирект на `/admin/login`

### 2. Управление проектами (кейсами)

**2.1 Список проектов**
- Страница `/admin/projects`
- Показывает все проекты в виде карточек
- Каждая карточка: превью изображения, название, категория, год
- Кнопки: "Редактировать", "Удалить"

**2.2 Добавление проекта**
- Страница `/admin/projects/new`
- Форма с полями:
  - Название (обязательно)
  - Описание (обязательно)
  - Категория (выбор из списка)
  - Год (обязательно)
  - Изображение (загрузка файла)
  - Alt текст для изображения
- Кнопка "Сохранить"

**2.3 Редактирование проекта**
- Страница `/admin/projects/[id]/edit`
- Та же форма что и при добавлении
- Поля заполнены текущими данными
- Кнопка "Сохранить изменения"

**2.4 Удаление проекта**
- Кнопка "Удалить" на карточке проекта
- Подтверждение: "Вы уверены?"
- После удаления обновляется список

### 3. Загрузка изображений

**3.1 Загрузка файла**
- Drag & drop или выбор файла
- Поддержка: JPG, PNG, WebP
- Максимальный размер: 5MB
- Превью после загрузки

**3.2 Хранение**
- Файлы сохраняются в `/public/uploads/`
- Имя файла: `{timestamp}-{original-name}`
- Путь в базе: `/uploads/{filename}`

### 4. Редактирование контактов

**4.1 Страница контактов**
- Страница `/admin/contacts`
- Форма с полями:
  - Email
  - Telegram
  - Behance
  - Dribbble
- Кнопка "Сохранить"

**4.2 Хранение**
- Данные в таблице `content` с ключом `contacts`
- JSON формат

### 5. Статистика

**5.1 Dashboard**
- Страница `/admin` (главная)
- Показывает:
  - Количество проектов
  - Просмотры за последние 30 дней
  - Последние 5 просмотров (страница, дата)

**5.2 Трекинг просмотров**
- Автоматический трекинг на публичных страницах
- Сохраняется: путь, дата, IP (опционально)
- Таблица `pageviews`

## Технические требования

### База данных
- SQLite файл `admin.db`
- Таблицы:
  - `users` - пользователи (1 админ)
  - `projects` - проекты
  - `content` - контакты и другой контент (key-value)
  - `pageviews` - статистика просмотров

### API Routes
- `/api/admin/auth/login` - POST - логин
- `/api/admin/projects` - GET/POST - список/создание
- `/api/admin/projects/[id]` - GET/PUT/DELETE - получить/обновить/удалить
- `/api/admin/upload` - POST - загрузка изображения
- `/api/admin/contacts` - GET/PUT - получить/обновить контакты
- `/api/admin/stats` - GET - статистика

### Авторизация API
- Токен передается в заголовке `Authorization: Bearer {token}`
- Проверка токена в каждом API route
- Если токен невалидный - 401 Unauthorized

## Структура страниц

```
/admin/login          - Страница логина
/admin                - Dashboard (статистика)
/admin/projects       - Список проектов
/admin/projects/new   - Добавить проект
/admin/projects/[id]/edit - Редактировать проект
/admin/contacts       - Редактировать контакты
```

## Что НЕ включаем (пока)
- ❌ Логи
- ❌ Бэкапы
- ❌ Rate limiting
- ❌ CSRF защита
- ❌ Сложная валидация
- ❌ Тесты
- ❌ Множественные пользователи
- ❌ Роли и права
